# Modbus 串口通信调试工具

一个基于 .NET 6 的 Modbus RTU 串口通信调试控制台程序，用于 Modbus 协议设备的数据读写与调试。

---

## 📋 项目简介

本项目是一个轻量级的 Modbus RTU 串口通信调试工具，通过简单的控制台命令即可完成对 Modbus 设备的读写操作。适用于工业自动化、物联网设备调试、传感器数据采集等场景。

### 主要功能

- 🔌 **串口通信管理** - 自动检测可用串口，支持波特率、数据位、停止位、校验位配置
- 📊 **Modbus RTU 协议** - 完整支持 Modbus RTU 模式，兼容主流 PLC 和工业设备
- 📖 **寄存器读写** - 支持读取/写入保持寄存器、输入寄存器、线圈、离散输入
- 📝 **数据格式化显示** - 支持 HEX、DEC、ASCII 多种数据格式输出
- 📋 **操作日志记录** - 完整的请求/响应日志，便于问题排查
- ⚡ **命令交互模式** - 友好的命令行交互界面，支持历史命令记录
